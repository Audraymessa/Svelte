Svelte è un approccio radicalmente nuovo alla creazione di interfacce utente. Sposta il lavoro dal browser alla fase di compilazione.

Cos'è Svelte?

Svelte è uno strumento per costruire applicazioni web. Come altri framework per interfacce utente, ti permette di costruire la tua app in modo dichiarativo usando componenti che combinano markup, stili e comportamenti.

Questi componenti vengono compilati in moduli JavaScript piccoli ed efficienti che eliminano il sovraccarico (overhead) tradizionalmente associato ai framework UI.

Puoi costruire l'intera app con Svelte (ad esempio usando SvelteKit), aggiungerlo incrementalmente a una codebase esistente, oppure distribuire componenti come pacchetti autonomi che funzionano ovunque.

Perché Svelte?

Svelte è un approccio radicalmente nuovo alla costruzione di interfacce utente. Mentre i framework tradizionali come React e Vue fanno gran parte del loro lavoro nel browser, Svelte sposta quel lavoro in una fase di compilazione che avviene quando costruisci la tua app. Il risultato? Applicazioni incredibilmente veloci che non richiedono framework pesanti da caricare nel browser dell'utente.

Zero Run Time

Svelte compila il tuo codice in JavaScript altamente ottimizzato durante la build, eliminando la necessità di un runtime pesante. Questo significa app più veloci e bundle più piccoli.

Nessun Virtual DOM

Svelte compila il codice in piccoli moduli JavaScript imperativi che aggiornano il DOM chirurgicamente.

Meno Codice

Scrivi componenti usando HTML, CSS e JavaScript standard. Meno boilerplate significa meno bug.

Reattività Vera

Non serve chiamare setState. La reattività è nel linguaggio stesso: count += 1.

Pronto a iniziare?

Svelte sta rivoluzionando il modo in cui costruiamo applicazioni web moderne.

Caratteristiche Tecniche

Esplora i concetti fondamentali di Svelte: componenti, reattività e gestione dello stato

Reattività in Svelte

La reattività in Svelte è dichiarativa e automatica. Usa il simbolo $: per creare dichiarazioni reattive che si aggiornano automaticamente quando le dipendenze cambiano.

Vantaggio: Nessun hook da ricordare, la reattività è integrata nel linguaggio.
  • Dichiarazioni reattive con $:
  • Aggiornamenti automatici del DOM
  • Nessun Virtual DOM diffing
Esempio di Codice
<script>
let count = 0;
// Reattività automatica
$: doubled = count * 2;
function increment() {
count += 1;
}
</script>

<button on:click={increment}>
Contatore: {count}
</button>

<p>Doppio: {doubled}</p>

Componenti Svelte

I componenti Svelte sono file singoli che contengono script, markup e stili. Le props vengono definite con export let e gli stili sono automaticamente scoped.

Vantaggio: CSS scoped automaticamente senza configurazione.
  • Single File Components
  • Props con export let
  • Slots per contenuto dinamico
Esempio di Codice
<script>
export let name = 'Mondo';
export let size = 'medium';
</script>

<div class="card {size}">
<h1>Ciao {name}!</h1>
<slot></slot>
</div>

<style>
.card { padding: 1rem; }
.medium { font-size: 1rem; }
</style>

Gestione dello Stato

Gli stores di Svelte forniscono un modo semplice per gestire lo stato globale. Usa il prefisso $ per sottoscriverti automaticamente.

Vantaggio: Gestione dello stato semplificata senza boilerplate.
  • Writable stores
  • Readable stores
  • Derived stores
Esempio di Codice
<script>
import { writable } from 'svelte/store';

const count = writable(0);

function increment() {
count.update(n => n + 1);
}
</script>

<button on:click={increment}>
Incrementa
</button>
<p>Valore: {$count}</p>

Come Funziona la Compilazione

Svelte non è una libreria che il browser deve eseguire: è un compilatore. Mentre costruisci la tua app, Svelte trasforma i tuoi componenti in codice JavaScript vanilla imperativo altamente efficiente.

Codice dichiarativo (HTML, CSS, JS)
2. Svelte Compila
Analisi e ottimizzazione alla build
3. Browser Esegue
JS veloce, nessun Virtual DOM
